 2.2 话题通信程序开发流程

➢ 任务
  ➢ 编写一个ROS2话题通信的程序，创建一个发布者（publisher）发送"counter"计
    数消息，和一个订阅者（subscriber）接收并打印这条消息
➢ 主要步骤
  ➢ 创建工作空间和功能包
  ➢ 编写发布者节点代码
  ➢ 编写订阅者节点代码
  ➢ 修改CMakeLists.txt
  ➢ 编译运行
  2.3 创建工作空间和功能包


 # 创建工作空间
 $ mkdir -p ~/ros2_ws/src

 # 创建功能包（依赖 rclcpp 和 std_msgs）
 $ ros2 pkg create pub_sub_demo --build-type
 ament_cmake --dependencies rclcpp std_msgs



➢ rclcpp 是 ROS 2 的 C++ 客户端库，为 C++ 开发者提
  供访问 ROS 2 核心功能（如话题、服务、参数）的
  API
➢ rclpy 是 ROS 2 的 Python 客户端库，为 Python 开发
  者提供同样的功能，但基于 Python 语言特性封装
  2.4 编写发布者和订阅者节点代码
